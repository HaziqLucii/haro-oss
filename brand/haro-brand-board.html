Themes — one token contract, many cartridges

A theme is not an accent swap — switching feels like a different game cartridge. The model is a family (data-theme — the look) × a mode (data-mode — light / dark ground). Every family ships both grounds; the appbar sun/moon flips the mode. Adding a family = one CSS file under styles/themes/<id>.css (a dark block scoped to :root[data-theme="<id>"] + a [data-mode="light"] block) plus one entry in frontend/src/themes.ts. The default family (Haro) lives in base.css; every partial reads only the tokens below, so the whole app reskins from that one contract.

The token contract

Every token a partial consumes. Define all of them per family (light overrides only what changes). Grouped by role:

  • Ground — --bg --panel --panel-2 --border --fg --dim
  • Signature — --accent --accent-ink --add (keep the gate green)
  • Status — --del --coral --blue --marker --amber --merged(-ink) --gh-pull --gh-push --danger --warn
  • Ink-on-fill — --on-fill --knob --preview-bg --shade
  • Shape — --radius-sm/md/lg --border-w (pixel theme flattens to 0 / 3px)
  • Shadow — --shadow --shadow-key --shadow-pop --edge --shadow-rgb
  • Type — --font-display --font-ui
  • Registry (optional) — editor (Monaco) + terminal (xterm ANSI) palettes, one per mode
Author rules
  • Contrast is AA per mode. Any token used as text (--accent --amber --danger --warn --dim --fg) must clear 4.5:1 on its ground — verify both grounds. A mode block must retune --warn/--danger, not inherit the dark values (they land at ~2:1 on a light panel).
  • Fills are the exception. White-on-color status badges/buttons run <4.5 by design — they’re large/bold and carry a border cue. Don’t chase them.
  • Spend saturation on small areas — chips, borders, pellets — never on large fills or text walls (soften big-area colors with dedicated tokens).
  • Reading voices stay put. --prompt --prose --mono --code are theme-independent; a pixel --font-display is for headings/badges/buttons only — body copy stays a readable sans.
  • Never hardcode a ground color in a partial — add a token to the contract instead, so theme N+1 can restyle it.
